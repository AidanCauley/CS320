## README Reflection 

Throughout these projects, I ensured that my code and software were functional and secure by applying structured testing practices and validating requirements through unit tests. Writing JUnit tests alongside implementation allowed me to confirm that each class behaved correctly under both normal and invalid conditions, which helped prevent defects and improve reliability. I interpreted user needs by carefully reviewing the project specifications and translating them into clear validation rules, such as field length limits and unique identifiers. This process reinforced the importance of understanding requirements before writing code. When designing software, I focused on modular structure and separation of responsibilities, which made the system easier to test and maintain. Using service classes with well-defined methods allowed me to verify behavior independently and improved overall code quality. These experiences strengthened my understanding of how testing, requirements analysis, and disciplined design work together to produce dependable software systems, and they represent skills that I plan to continue developing in future projects.
